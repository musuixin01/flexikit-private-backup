权限与隐私

  • activeTab：只有你点击扩展时，才临时读取当前标签页的标题、URL、描述和 favicon。
  • storage：保存 API 地址和扩展独立登录会话，数据仅保存在浏览器本机。
  • API Host：只向你明确授权的 FlexiKit API 主机发起请求，不默认拥有所有网站访问权。
  • 不会后台遍历浏览历史，不会采集页面正文，不会保存登录密码。
