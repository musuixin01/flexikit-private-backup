# FKI-20261008-001 · Windows 主窗口右/底部缩放跳动
## 现象
用户多次反馈 Windows 主窗口右、底及右下角快拖时内容与外框分离、黑白闪动，不能凭静态测试结果宣布解决。

## 复现
启动真正的桌面开发版，以鼠标连续拖右/底/角，在不同 DPI 和最大化/还原操作中目视记录；自动几何模拟不代表 DWM 呈现帧。

## 根因及证据
已确证根滚动条曾占据右缘 8px 热区，某个中间版本的工作区又被缩窄约 8px；同步尺寸采样在处理中偶有最高约 6–7px 差，命令返回后通常不超过 1px。DWM 可见闪动的最终根因尚未确证。

## 修复与变更
已有工作区改动使主内容全宽、scrollbar-gutter 稳定、热区为 4px；不采用禁用 GPU/DirectComposition 的实验方案，因为用户对照效果更差。用户已要求暂缓真正的缩放问题，不应擅自继续修改。

## 验证与边界
五档尺寸、HitTest、DOM 滚动与 201 次脚本缩放有通过证据；用户真实连续快拖、跨 DPI/双屏、DWM 呈现终验**未完成**。状态保持 PAUSED。

## 防复发
保留隔离最小复现和默认合成基线；恢复调查时必须进行真实鼠标快拖和多 DPI 视觉验证，不将几何 PASS 误当 UI 验收。
