# FKI-20261010-003 · 原 Backend 本地依赖缺失
## 现象
原工作目录缺少 @nestjs/cli、class-transformer 等依赖，Nest build/测试在加载时 MODULE_NOT_FOUND，业务断言未执行。

## 复现
只读检查原 backend/node_modules 的包存在性及 npm ls 缺失信息；不为复现而执行可能覆盖用户依赖的 npm ci。

## 根因及证据
本机依赖目录安装不完整；尚无证据证明属于业务源码编译错误。

## 修复与变更
在独立系统 TEMP UUID 目录安装约 590 个后端包并复制非敏感源码，避开原有依赖；原仓库 backend/node_modules **仍未修复**。

## 验证与边界
隔离 Nest build 与 tsc --noEmit、原先受阻的 Browser/多客户端回归已 PASS；这不代表本地运行环境恢复或生产后端已上线，因此状态 BLOCKED。

## 防复发
依赖校验走安全隔离工作区；原项目要重装须确认无并发服务和数据风险，重装后再次执行完整测试。
