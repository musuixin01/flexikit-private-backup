# FKI-20261010-002 · PostgreSQL 隔离测试 TypeORM 参数错配
## 现象
独立 PG 客户端能够连接测试集群，但 TypeORM DataSource 用非预期账号认证失败。

## 复现
在完全隔离的 TEMP PostgreSQL 集群中运行配对测试；原测试脚本给 TypeORM 使用 pg 客户端的 user 字段，而不是 username。禁止在真实数据服务复现。

## 根因及证据
pg 和 TypeORM 的连接参数名称不同：pg 使用 user，TypeORM 使用 username。这是测试配置错误，不是用户数据库被修改或生产服务故障。

## 修复与变更
backend/scripts/stage6-extension-pair-postgres-isolated.mjs 改用 username: connection.user。失败的独立实例停止清理，不影响正式 PostgreSQL。

## 验证与边界
新建 PG18.4 TEMP 集群真实迁移 up/down、并发审批/领取、事务回滚与再次运行 PASS。VERIFIED **仅限隔离 PG18.4 测试脚本**；PG16、真实 Nest/Chrome E2E 仍需验收。

## 防复发
针对客户端与 ORM 使用各自类型契约；保留 TEMP UUID 和 SHOW data_directory 双重守卫，杜绝误操作现有服务。
